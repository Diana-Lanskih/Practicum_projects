# Practicum_projects

Проект Nº1: Разработка спецификации требований для новой версии приложения
 - Задача: Расширить функций для запоминания слов (карточки, видео).
 - Результат: Детальная SRS с Use Case, FR и глоссарием.
 - Инструменты: UML Use Case (графическая, табличная форма), draw.io, Google Docs.
 - Артефакты: Спецификация требований к ПО Chatty 2.0 (документ, включающий обновленные диаграммы, FR, глоссарий).

Проект №2: Моделированние данных и работа с базой данных интернет-магазина
 - Задача: Составить логическую модель данных, привести к 3НФ, разработать глоссарий
 - Результат: Детальная SRS с ERD в 3НФ и глоссарием.
 - Инструменты: ERD Crow's Foot, drawio.io, Google Docs.
 - Артефвкты: Спецификация требований к ПО Накарабине 1.0 (документ, включающий диаграммы и глоссарий).

Проект Nº3: Разработка бэклога мобильного приложения для сети клиник
 - Задача: Автоматизация процессов лечения и обследований.
 - Результат: Выделен MVP, который закрывает основные боли пациентов: получение цифровых назначений, просмотр расписания процедурного кабинета и доступ к результатам анализов
 - Инструменты: User Story Mapping, INVEST, MVP, User Story, Job Story, Miro, Figma, draw.io
 - Артефакты:
Карта пользовательских историй с выделенным MVP.
Набор прототипов и раскадровок в Figma.
Контекстная и логическая DFD-диаграммы.

Проект №4: Реализация новой функции в приложения стримингово сервиса
 - Задача: Постановка задачи на разработку новой операции API

 - Артефакты: UML Sequence Diagram, задача на разработку с новой операцией API
