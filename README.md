# Practicum_projects

Проект Nº1: Разработка спецификации требований для новой версии приложения
 - Задача: Расширить функций для запоминания слов (карточки, видео).
 - Результат: Детальная SRS с Use Case, FR и глоссарием.
 - Инструменты: UML Use Case, draw.io/Miro/Google Docs.
 - Артефакты: Спецификация требований к ПО Chatty 2.0 (документ, включающий обновленные диаграммы, FR, глоссарий).

Проект Nº3: Разработка бэклога мобильного приложения для сети клиник
 - Задача: Автоматизация процессов лечения и обследований.
 - Результат: Выделен MVP, который закрывает основные боли пациентов: получение цифровых назначений, просмотр расписания процедурного кабинета и доступ к результатам анализов
 - Инструменты: User Story Mapping, INVEST, MVP, Miro, Figma, draw.io
 - Артефакты:
Карта пользовательских историй с выделенным MVP.
Набор прототипов и раскадровок в Figma.
Контекстная и логическая DFD-диаграммы.
